Cognitive Authenticity Detection

CAD analyses how student answers are constructed — measuring semantic richness, conceptual linkage, and confidence signals — to produce a Genuine Understanding Score (GUS) instead of a binary right/wrong judgment.

GUS metric TF-IDF + BERT Bayesian calibration

The problem

Students often memorise correct answers without genuine understanding. Standard graders check keywords or correctness — not cognitive depth.

Our solution

CAD combines NLP (TF-IDF baseline, BERT fine-tune) with a Bayesian confidence wrapper and handcrafted linguistic features to score reasoning depth.

GUS score

0–100 score: semantic depth (40%), conceptual links (30%), lexical richness (15%), Bayesian confidence (15%). Above 70 = Deep; 40–70 = Moderate; below 40 = Shallow.

Tech stack

Python 3.9 · scikit-learn · HuggingFace Transformers · PyTorch · Flask. Local inference only — no student data leaves the server.
